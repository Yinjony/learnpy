# Offline GRPO World-Model Training

`train_grpo_world_ours.py` converts the previous pairwise DPO entry point into
offline diffusion-GRPO training for the camera-conditioned Wan2.1 world model.

## Required checkpoint

Pass a learned PRoPE checkpoint with:

```bash
--enable_world_model \
--world_model_modules_path /path/to/score_modules-stage1.safetensors
```

The checkpoint must contain `blocks.*.self_attn.prope_o.*` parameters. The
target and frozen reference models both load the same PRoPE weights. GRPO then
trains the target LoRA parameters only.

## CSV contract

Each CSV row is one offline rollout candidate. Rows are grouped by
`original_video`. Every row in one group must share:

- `prompt`
- `original_video`, or the configured `--history_video_column`
- `camera_pose_path`, or the configured `--camera_pose_column`

Each group must contain at least `--grpo_group_size` candidates. The candidate
video path is read from `video_filename`. Rewards are computed from normalized
`VQ` and `generated_motion_score` columns by default.

The previous DPO metadata often contains only two seeds per source video. Such
data can be used with `--grpo_group_size=2`, but generating at least four
candidates per state-action group gives a more useful group-relative signal.
Existing DPO CSV files also need a shared `camera_pose_path` column before they
can train the world-model entry point.

Example columns:

```text
original_video,video_filename,prompt,camera_pose_path,VQ,generated_motion_score
```

## Training step

For each state-action group, the dataset samples `--grpo_group_size` candidate
future videos. The training loop:

1. Encodes the shared history and all candidate videos with the Wan VAE.
2. Builds teacher-forcing windows with clean history frames and noisy future
   frames.
3. Passes the shared camera trajectory through Wan self-attention PRoPE.
4. Uses the same diffusion noise and timestep for all candidates in one group.
5. Normalizes rewards inside the group to produce relative advantages.
6. Computes a clipped GRPO surrogate from target-versus-reference future-frame
   denoising MSE.

This is an offline GRPO approximation: candidate videos must already exist and
should be generated by the reference or behavior policy. It does not perform
online sample-decode-reward-update rollouts inside the training process.

## Launch

Edit the paths in `train_grpo_world_ours.sh`, then launch it from this
directory:

```bash
bash train_grpo_world_ours.sh
```
